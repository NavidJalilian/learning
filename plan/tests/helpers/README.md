# Agent helper scripts

Throwaway scripts the build agents wrote while checking their lessons, kept so nothing from the run is lost:
screenshot capture (`shot*-<id>.js`), extra play paths (`alt-`, `ooo-` out-of-order runs, `bo-`, `near-`, `order-`),
debugging (`dbg*`, `q*`, `x*`, `st.js`), and planner/reviewer helpers (`gen_ch11.py`, `gen_ch14.py`, `optlen12.py`,
`txt12.sh`). `BUILD-PROMPT.txt` and `running.txt` are early orchestration notes. Not needed to play the lessons.
Several expect the session scratchpad path; adjust paths before re-running.
